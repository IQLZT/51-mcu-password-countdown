# -STC89C51-C4-
本设计以 STC89C51 单片机为控制核心，开发一套兼具定时起爆、密码解锁、倒计时计数、声光提示及模拟爆炸功能的控制系统。通过Proteus完成硬件电路的模块化搭建，KEIL uVision实现汇编程序的编写与编译，采用 LCD1602 显示模块、4×4 矩阵键盘输入模块、声光提示模块构建硬件框架，利用单片机内部定时器 T0 实现高精度倒计时。系统经仿真验证与实物开发板测试，可稳定完成定时设定、密码校验、状态提示等核心功能，定时精度误差≤1 秒，密码校验准确率达 100%。该设计采用模块化软硬件架构，兼具实用性与可操作性。
